# Lailak reviewer demo
A public construction-finance evidence review demonstration.
## Deploy on Streamlit Community Cloud
1. Put this folder's CONTENTS at the root of a new public GitHub repository.
2. In share.streamlit.io choose Create app / deploy from GitHub.
3. Select the repository, branch main, and app.py. Use Python 3.12.
4. Deploy. packages.txt installs the server scan reader and English/Russian/Uzbek models.
5. Open the public URL signed out and run both synthetic packets before submitting the link.
No paid API key is required. Baidu's optional public demo is quota-limited and currently disabled.
## Reviewer workflow
Try the clean and repeated-support example packets. Inspect source pages and download the report.
Upload only public or redacted documents. The current parser supports the explicit labels in engine.py.
## Test provenance
Mac Apple Vision: 69/72 regression fields and 36/36 fresh synthetic challenge fields.
Baidu official demo: 18/18 fields across three generated language samples.
The HOSTED scan reader is Tesseract and these scores must not be attributed to it.
Embedded-text PDFs are read directly using PyMuPDF.
Corrected satellite results are public examples without independent stage labels.
The app does not verify authenticity, approve funding, predict defaults or establish real-bank accuracy.
